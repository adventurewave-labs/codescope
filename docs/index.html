What it does

One binary, whole graph

Indexes any repo into a queryable code graph so agents read structure before they write.

MCP, CLI, JSON

Three doors into the same index: MCP for coding agents, CLI for humans, JSON for everything else.

Rust-fast

A single static binary — no daemon zoo, no language runtime to babysit.
