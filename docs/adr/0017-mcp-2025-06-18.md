# ADR-0017: MCP 2025-06-18 Alignment

**Status:** Accepted (amends ADR-0010)

**Date:** 2026-09-26

## Decision

- **Version negotiation:** echo the client's `protocolVersion` if it is one of
  `2025-06-18`, `2025-03-26`, `2024-11-05`; otherwise offer `2025-06-18`.
- **Structured output:** every tool result carries `structuredContent` (the JSON
  object) *and* the same JSON as a text block for older clients.
- **Tool annotations + titles:** `readOnlyHint` (all but `cs_index`),
  `destructiveHint: false`, `idempotentHint: true`, `openWorldHint: false`.
- **In-band tool errors:** execution failures return `isError: true` content so
  the model can recover; protocol errors (unknown tool, missing params) remain
  JSON-RPC errors.
- **Server `instructions`** in `initialize` describe the recommended workflow
  (map → callers/blast radius → diff impact).
- **Auto-index:** the first query builds the index if none exists — agents no
  longer need to remember `cs_index`.
- **Did-you-mean:** name-based queries that match nothing return `suggestions`
  (case-insensitive exact → substring → bounded Levenshtein).
